# Manuscript

Target: *Radiology: Artificial Intelligence*, **Original Research** — 3000 words
(Introduction–Discussion), 250-word abstract, 35 references, 6 figures, 4 tables.
Why this article type and not Technical Developments: [docs/JOURNAL_FIT.md](../docs/JOURNAL_FIT.md) §1.

## Files — four separate uploads, as the journal requires

| file | what it is |
|---|---|
| `cover_letter.tex` | cover letter; carries the four RSNA-required items plus the AI-use and data-control disclosures |
| `title_page.tex` | full title page — authors, affiliations, funding, conflicts, IRB, data sharing |
| `main.tex` | the **anonymized** manuscript: abbreviated title page, abstract, body, acknowledgments, references, figure legends, tables |
| `figures.tex` | the combined figure document — each figure followed by its legend, in citation order |

The journal uses **double-anonymized peer review**. `main.tex` must contain no
author names, institutions, acknowledgments, or identifying URLs; that is
enforced by `tests/test_manuscript_compliance.py`, not by proofreading. The real
repository URL goes in the cover letter and on the title page only.

Build:

```bash
for f in cover_letter title_page main figures; do tectonic $f.tex; done
```

## House style

Formatted against [docs/RSNA_STYLE.md](../docs/RSNA_STYLE.md), which records
every rule with its evidence and confidence tier. The ones most easily lost:

- double spaced, ragged right, 11 pt, **no page numbers** (ScholarOne adds them)
- order is body → **acknowledgments → references** → figure legends → tables
- American spelling; **section** not slice; **patients** never subjects
- italic *P*, no leading zero (`P = .03`); `95% CI: lower, upper` with a comma
- comparison symbols only inside parentheses — the significance threshold is
  written out as "*P* values less than .05"
- references cited as `(1)`, in citation order, no italics, DOIs supplied
- summary statement capped at **255 characters**, not words
- a legend showing patient images must state each patient's age and sex

**At revision the figures must be re-exported.** PNG is not an accepted format:
clinical images need TIF/PSD/AI/EPS at 300 dpi and graphs at 1200 dpi, one file
per figure. `figures.tex` carries the details.

Figures are read from `../figures/` and regenerated by
`python -m theia.analysis.figures` and `python -m theia.analysis.flowchart`.
Every number in the text comes from `../results/` via `../scripts/reproduce.sh`.

## Compliance is tested, not remembered

`tests/test_manuscript_compliance.py` fails the build if the abstract or body
exceeds its limit, if a required element goes missing (Summary Statement, Key
Points, the *P*-value threshold, statistical software versions, the ethics
section), if the abstract grows a `Background` heading (that is *Radiology*
style, not this journal's), if an identifying string reappears in the main file,
or if the primary-endpoint numbers stop matching
`results/external_grounding_canonical.json`.

**Image licensing.** Figure 6 (attention overlays) shows NSCLC-Radiogenomics
images only, which are **CC BY 3.0** and republishable with the attribution given
in the bibliography. NSCLC-Radiomics is **CC BY-NC 3.0**; no NSCLC-Radiomics pixel
data appears in any figure, only derived summary statistics. That distinction is
deliberate — a non-commercial licence in a subscription journal is a question best
not raised.

## Before submission — author actions, none of which can be done from here

- **Institutional review board determination.** Approval, a consent waiver, or an
  exempt / not-human-subjects-research determination with reference number and
  date. The manuscript carries a boxed placeholder in Methods; it must not be
  submitted with the box in it.
- Author list, affiliations, degrees, ORCIDs; corresponding author details
- Funding and conflicts; ICMJE forms for every author
- OSF registration ID and Zenodo DOI (ANALYSIS_PLAN §0 still reads *to be pasted*)
- An anonymized repository mirror for reviewers
- Statistical review — the journal advises consultation before analysis, and it
  has not happened
