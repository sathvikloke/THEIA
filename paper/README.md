# Manuscript

Build:

```bash
tectonic main.tex        # or: pdflatex main.tex (twice, for cross-refs)
```

Figures are read from `../figures/` and regenerated by
`python -m theia.analysis.figures` and `python -m theia.analysis.flowchart`.
Every number in the text comes from `../results/` via `../scripts/reproduce.sh`.

**Image licensing.** Figure 6 (attention overlays) shows NSCLC-Radiogenomics
images only, which are **CC BY 3.0** and republishable with the attribution given
in the bibliography. NSCLC-Radiomics is **CC BY-NC 3.0**; no NSCLC-Radiomics pixel
data appears in any figure, only derived summary statistics. That distinction is
deliberate — a non-commercial licence in a subscription journal is a question best
not raised.

**Before submission:** author list, affiliations, funding, conflicts, OSF
registration ID and Zenodo DOI (ANALYSIS_PLAN §0), and statistical review.
