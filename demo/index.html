On the real NSCLC-RADIOGENOMICS cohort the current model does not separate EGFR status: pooled out-of-fold AUC 0.426, 95% CI [0.307, 0.546], over 117 patients with 23 positives — an interval that spans chance. A permutation test over 200 label shuffles returns p = 0.52, and a conventional radiomics baseline finds nothing either (p = 0.94). Treat every number on this page as a layout placeholder.
