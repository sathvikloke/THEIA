This interface uses synthetic schematic scans and mock predictions to demonstrate the intended THEIA experience — the linkage between a predicted mutation, the image regions behind it, and a grounded written rationale. No real patient data, no trained model. It is the front end that the NSCLC-RADIOGENOMICS pipeline plugs into, and the same layout adapts directly into the blinded reader-study tool.
